# 개념

플러그인의 설계는 이런 형태인 이유를 설명하는 3가지 개념에 기반합니다. 각 개념마다 별도 페이지가 있습니다.

이 페이지들 중 일부는 *동반 paper* — 이 평가 방법론을 도입·검증한 방법론 연구 — 를 보고 수치와 재현 자료의 출처로 인용합니다.

| 개념 | 의미 | 플러그인 내 위치 |
|---|---|---|
| [실천 기반 연구](practice-based-research.md) | 작가는 만드는 동안 형성되는 앎이 있고, 문서만으로 전달되지 않음 | per-layer instrument의 종속변수가 Schön/Polanyi/Borgdorff에 grounding된 이유 |
| [Reconstruction benchmark](reconstruction-benchmark.md) | 출판된 paper를 숨기고 사전 자료로 재구성, 층별 측정 | 동반 paper가 도입하는 평가 방법론 |
| [Inversion rule](inversion-rule.md) | held-out paper와의 높은 유사도를 contamination 의심으로 읽음 | `art-reviewer` integrity gate와 `art-paper citation-check` 모드 |

이 세 개념이 함께 설명하는 것:

1. **왜** 플러그인이 AI가 아니라 작가에게 provocation과 reflection 작성을 요청하는지
2. **어떻게** integrity gate가 "memorisation" 경고 기준을 결정하는지
3. **무엇을** 플러그인이 출력에서 주장하고 주장하지 않는지

방법론을 처음 접한다면 이 순서로: 실천 기반 연구 → reconstruction benchmark → inversion rule.
